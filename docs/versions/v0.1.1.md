# Showup v0.1.1

**Release date:** 2026-10-14
**Status:** MVP / prototype

## Purpose

Prevent people from saving a random location (for example, their home) as "Gym 1" and earning Showups without going to a gym.

## What changed

- Gym search still shows any kind of place (addresses, landmarks, businesses), so users can find their gym however they search.
- When a place is **selected**, Showup also asks Google for its categories (`types`) and checks them with `isFitnessPlace` (`src/services/gymValidation.ts`).
- The place is accepted only if it has at least one type in `ALLOWED_GYM_PLACE_TYPES` (`src/config/constants.ts`):
  `gym`, `fitness_center`, `yoga_studio`, `sports_club`, `sports_complex`, `sports_activity_location`, `sports_coaching`, `swimming_pool`, `athletic_field`, `ice_skating_rink`.
- Otherwise it shows: *Not a gym. "&lt;place name&gt;" isn't listed on Google Maps as a gym, fitness centre or sports facility. Please select another place.* The Save button stays disabled.

## Technical decisions

- **Reject when unsure.** A place with no types, or the wrong types, is rejected. Accepting it would reopen the loophole this release closes.
- **Types are not stored.** They are only needed at selection time, so the saved data model is unchanged and no migration is needed.
- **The list lives in one place** (`constants.ts`) so it is easy to adjust.

## Known limitations

- Relies on Google's categories. A genuine gym that Google has categorised wrongly cannot be saved. The fix is to add its type to the list, or to correct its listing on Google Maps.
- Gyms saved under v0.1.0 are not re-checked.
- It is still a client-side check. A technical user could edit localStorage. This is acceptable for the MVP and would be enforced on a server later.
